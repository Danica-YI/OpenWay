# Code Network Hackathon — OpenWay

A responsive web app that provides far more detailed building accessibility
information than general mapping services: which side the ramp is on, what level
the accessible toilet is, where the disability parking actually is.

The app lives in [`access-ramp-navigator/`](access-ramp-navigator/).
**See [access-ramp-navigator/README.md](access-ramp-navigator/README.md) for setup.**

## Quick start

```bash
cd access-ramp-navigator
npm install
npm run dev
```

Then open <http://localhost:5173>.

Requires **Node.js 22.13 or newer** (`node -v` to check).
